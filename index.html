The UI/UX Designer Role

Junior UI/UX Designer Position

Job Summary & Impact

As a Junior UI/UX Designer at Nexora Technology, you will craft engaging user interfaces (UI) and design intuitive user experiences (UX) for both mobile applications and web platforms.


Key Impact: Translate complex client needs and user research into beautiful, functional, and seamless visual journeys—bridging aesthetics with functionality.

Candidate Requirements

  • UI/UX Principles: Solid understanding of core UI/UX design theories, layout structures, and visual hierarchy.
  • Design Fundamentals: Practical knowledge of typography, color harmony, visual balance, and prototyping tools.
  • Soft Skills: Creative mindset, detail-oriented, effective communication, and ability to thrive under deadlines.

Key Responsibilities

  • Wireframing & Prototyping: Create wireframes, interactive mockups, and prototypes for mobile and web applications.
  • User Interface Design: Design UI components that are visually attractive, consistent, modern, and user-friendly.
  • User Research: Conduct user research, analyze user needs, and map out effective user journeys.
  • Cross-Functional Collaboration: Work closely with software developers and product managers to ensure design feasibility and execution.
  • Iterative Improvement: Evaluate and refine visual designs based on usability testing and user feedback.
